# /homework — домашка с Тьютором

Запрос: $ARGUMENTS

1. Прочитай `Тьютор/ВОРКФЛОУ.md` и действуй по режиму **А**, начиная со **«Старта домашки — сводки хвостов»**.
2. Сначала мини-тесты: «📋 Мини-тест по прошлой сессии» в начале текущей сессии и текущего интереса, плюс незаполненные мини-тесты в старых файлах текущей и прошлой недели. Есть — они первыми в сводке, «сейчас»; это тест — без подсказок. Проверяет их Ментор.
3. Сводка — 3–6 строк: что открыто и **в какой день** сделать каждый пункт, по правилу «Хвосты — равномерно по неделе» (режим А воркфлоу): свой срок у каждого хвоста, в день — сессия плюс один хвост, в выходные не сгружать. Учитывай время, которое назвал пользователь, и день недели.
4. Затем — по выбору пользователя: сопровождение задания лесенкой подсказок. Тесты до сдачи — без помощи (раздел 1 воркфлоу).
5. Подсказки — в строку «Подсказки Тьютора» отчёта; после встречи — запись в `Тьютор/ЖУРНАЛ.md`. Перечитай файлы перед правкой и проверь после записи.
6. **Файл сессии — целиком, по порядку** — правило в `Тьютор/ВОРКФЛОУ.md`, раздел 1; соблюдай его полностью: мини-тест прошлой сессии (без подсказок) → разминка → «📚 Материалы» целиком (настоятельно рекомендуются к изучению перед заданиями); **каждое интерактивное демо** (HTML из `Материалы/Демо/`, выноска «🎮 Интерактивное демо») — ссылкой отдельной строкой с просьбой открыть и ознакомиться, а часть «после заданий» — напомнить после них → каждое задание дословной цитатой → связь с практикой и мостик → отчёт → практика и «код руками» недели в `НЕДЕЛЯ.md`, если не сданы («код руками» — подсказки по лесенке можно; в плане недели — «📥 сдана»).
