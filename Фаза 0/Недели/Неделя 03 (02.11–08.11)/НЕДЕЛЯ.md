## ⌨️ Код руками

> Без автодополнения, агентов и поиска — но с Тьютором можно: подсказки по лесенке (`/tutor`). 15–30 мин. Ошибки — нормально: это тренировка, а не экзамен.

**Задача.** Функция `update_settings(settings, changes)` возвращает **новый** словарь: настройки с применёнными изменениями. Исходный словарь не меняется.

Дано и что должно получиться:
```python
base = {"timeout": 30, "retries": 3}

new = update_settings(base, {"timeout": 60})
print(new)   # {'timeout': 60, 'retries': 3}
print(base)  # {'timeout': 30, 'retries': 3} — не изменился

same = update_settings(base, {})
print(same == base, same is base)   # True False — равны, но это разные объекты
```
**Что сдать:** функция, вывод трёх `print` и одна строка: что сломается, если написать `result = settings` вместо копии. Плюс сложность по времени и памяти.

**Ответ:**
```python
def update_settings(settings, changes):
    result = settings.copy()
    result.update(changes)
    return result
```

**Вывод трёх print:**
```text
{'timeout': 60, 'retries': 3}
{'timeout': 30, 'retries': 3}
True False
```

**Что сломается, если написать `result = settings`:**
Сломается создание нового словаря: `result` будет ссылаться на тот же объект, и мы будем перезаписывать значения старого словаря (изменения затронут оригинал).

**Сложность:**
- Время: $O(N)$
- Память: $O(N)$

✍️ продиктовано
- **Подсказки Тьютора:** ур. 2 — подсказано, что `.update()` работает in-place и возвращает `None`, поэтому нужно разделить копирование/обновление и возврат `result` на две строки.

> ✅ **Проверка *(Ментор)*:** *13.11 (пт) · Claude Opus 5.5*
> - **✅ Сдана.** Функция верна: копия, затем `update`, возврат копии; три вывода совпадают с ожидаемыми; `result = settings` — верно: та же ссылка, правка заденет оригинал.
> - 💡 Сложность точнее — O(n + m): n — размер настроек (копия), m — число изменений (`update`). Память — O(n) на копию.
> - 💡 Копия поверхностная: если в настройках вложенный словарь (`{"db": {"host": …}}`), правка `new["db"]["host"]` изменит и `base`. Для вложенных — `copy.deepcopy`. Это не входило в задачу — на будущее.
> - Подсказка ур. 2 на `update()` — нормально: «код руками» — тренировка, не тест.
