# 🤝 Контракт автономии: <система или агент>

> **Что это.** Договор между тобой и агентом: что он делает сам, где зовёт человека, что ему нельзя, сколько он может потратить, что делает при сбое и чем его работа проверяется без тебя. Раздел design doc любой системы, где есть агент (ROADMAP, «Требования к любому учебному проекту», п. 4a).
> **Зачем.** Чем дольше и самостоятельнее работает агент, тем меньше пользы от ручной проверки каждого шага и тем больше — от границ и проверок, заложенных заранее. Контракт — место, где эти границы записаны, чтобы их можно было проверить, а не держать в голове.
> **Как растёт:** первая версия — `0.AGT.07` (неделя 9 Фазы 0, полигон: таблица «сам / спрашивает / запрещено»); в Фазе 1 — политика в коде и метрики основной системы; в Фазе 2 — на живом процессе с пользователями. Карта по фазам — ROADMAP, раздел контракта автономии.

## 1. Задача и что считается результатом

Одна строка задачи — и как отличить «сделано» от «сделано плохо». Результат — то, за что заплатил бы заказчик, а не «агент отработал».

| Задача | Результат — «сделано» | Не результат, хотя похоже |
|---|---|---|
| | | |

**Образец строки** (на другом агенте — разборщик входящих писем поддержки): `разобрать письмо и подготовить ответ · клиент получил верный ответ без участия оператора · ответ отправлен, но клиент написал повторно по тому же вопросу`.

## 2. Сам / спрашивает / запрещено

Каждое действие агента — в одну из трёх колонок. Критерий «спрашивает» — необратимость, деньги, внешний мир, чужие данные, а не «на всякий случай».

| Действие | Сам | Спрашивает человека | Запрещено | Почему так |
|---|---|---|---|---|
| | | | | |

**Образец строки:** `отправить ответ клиенту · — · да, если сумма возврата > 0 · — · деньги и обязательство перед клиентом`.

## 4. Что при сбое

Сбой — норма для долгой задачи: упал процесс, отвалился инструмент, модель вернула мусор. Здесь — что происходит, чтобы задача не начиналась с нуля и внешние действия не повторялись дважды.

| Сбой | Где задача продолжится (чекпоинт) | Повтор безопасен? (идемпотентность) | Компенсация уже сделанного | Кого зовём |
|---|---|---|---|---|
| | | | | |

## 5. Как проверяется без человека

| Что проверяем | Чем (eval, инвариант, тест-свойство, монитор, лог с доказательством) | Когда (на каждом прогоне, раз в день, при выпуске) | Что при провале |
|---|---|---|---|
| | | | |

Ручное ревью — только по риску: права, внешние действия, секреты, тесты. Остальное — по доказательствам.
