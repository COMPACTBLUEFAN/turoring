# 🔭 Скаут — интересное для отслеживания

> **Зачем.** Через 6–10 лет ценность может оказаться в направлениях, которых сегодня почти нет. Скаут заранее замечает такие направления на стыке интересов пользователя, следит за их сигналами и вовремя предлагает темы для изучения — даже далёкие от текущего профиля и даже до развилки D3.
> **Кто ведёт.** Агент: месячный аудит (сценарий J в `AGENTS.md`, пункт «Скаут») — отслеживание, новые направления, предложения; квартальный аудит (сценарий J2) — глубокий разбор и чистка файла. Пользователь может добавить направление или область в любой момент.
> **Ничего не меняет в плане сам.** Скаут только наблюдает и предлагает. Тема попадает в обучение (`ROADMAP.md`) только с согласия пользователя — через пункт «Нужно согласие» аудита.
> **Связь с ROADMAP:** раздел «🔭 Скаут» там — короткая ссылка сюда; на развилке D3 направления 🟢 рассматриваются как кандидаты в ветки.

### Лимиты — чтобы файл не разрастался

- **Активных направлений** (🔭, 🟡, 🟢) — без жёсткого лимита (решение 08.11.2026); на аудитах самые неинтересные и бесперспективные снимаются.
- **❌ снятые** — переносятся в «Архив» внизу одной строкой: направление, дата, причина.
- **Предложения к изучению** с решением старше полугода — сворачиваются в одну строку на квартал («Q1 2027: принято 2, отклонено 1 — …»).
- **Чистка** — на каждом квартальном аудите.
