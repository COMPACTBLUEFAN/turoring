Не бизнес и не бизнес-план — **решение**, обоснованное проверенными числами. «Ни одна ниша не годится» — законный исход.
> **Формат.** Отдельная практика по желанию, **вне учёта недели**: без обязательного слота, оценки и долгов; время подготовки, контактов и разбора учитывается в общей фактической нагрузке, ничего не блокирует (правило 27 `AGENTS.md`). Шаги — файлы `Шаг N — <что>.md`, следующий выдаётся, когда предыдущий проверен.

Жёсткие рамки, которые отсеивают ниши **до** всякого анализа. Заполняется один раз на Шаге 1 и меняется только осознанно: если сито поменять под понравившуюся идею, оно перестаёт работать.

| Параметр | Значение | Почему именно так |
|---|---|---|
| Деньги на старт, ₽ | *[заполнить]* | Больше — нет; меньше — можно |
| Личных часов в неделю | *[заполнить]* | При учёбе 8–12 ч остаётся не так много |
| Минимальная прибыль, ₽/мес | *[заполнить]* | Ниже — не имеет смысла тратить жизнь |
| Срок до первых денег | *[заполнить]* | Наличная подушка не бесконечна |
| География | *[заполнить]* | Екатеринбург? область? удалённо? |
| Табу | *[заполнить]* | Что не буду делать ни за какие деньги |
| Мои активы и рычаги | *[заполнить]* | Опыт 1С и инфраструктуры, знание закупок, доступ к людям, оборудование, время |

> **Активы — самое важное поле.** Ниша, где ваши активы дают преимущество, стоит десяти ниш, где вы просто «тоже хотите попробовать».

## 4. Дневник цифр

Всё, что измерено, — здесь, с пометкой и ссылкой. Формат: `число · ФАКТ/ОЦЕНКА/РАСЧЁТ · источник или формула`.

- `ФАКТ` — есть проверяемое свидетельство: ссылка, файл коммерческого предложения, датированная запись разговора или наблюдение с условиями замера. Фиксируй границы вывода: «клиент сказал, что купит» подтверждает слова клиента, но не покупку.
- `ОЦЕНКА` — есть основание (почему так считаю), но нет источника.
- `РАСЧЁТ` — есть формула и входные числа.

| Дата | Число | Тип | Источник или формула |
|---|---|---|---|
| | | | |

**Учёт времени:** подготовка / контакты и выезды / анализ результатов — отдельно, затем сумма. По умолчанию один полевой заход — до 2 часов активной работы и до 3 контактов; ожидание ответа фиксируется календарным сроком. Не уложился — промежуточный результат и перенос, без обязанности догонять.
