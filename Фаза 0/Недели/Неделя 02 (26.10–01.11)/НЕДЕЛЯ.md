## ⌨️ Код руками

**Задача:** напиши итеративный бинарный поиск `binary_search(items, target)`: `items` — отсортированный список чисел, функция возвращает индекс `target` или `-1`, если его нет. Без срезов (`items[a:b]`) и без рекурсии — только индексы `left` и `right`. Покажи три вызова: элемент есть в середине, элемента нет, пустой список. Отдельной строкой оцени сложность по времени и по памяти — и почему по памяти она лучше рекурсивной версии со срезами.

**Ответ:**
```python
def binary_search(items, target):
    left = 0
    right = len(items) - 1

    while left <= right:
        mid = (left + right) // 2
        if items[mid] == target:
            return mid
        elif items[mid] < target:
            left = mid + 1
        else:
            right = mid - 1

    return -1

# Три вызова:
# 1. Элемент есть в середине: вернёт индекс 2
print(binary_search([1, 3, 5, 7, 9], 5))

# 2. Элемента нет: вернёт -1
print(binary_search([1, 3, 5, 7, 9], 4))

# 3. Пустой список: вернёт -1
print(binary_search([], 5))
```

**Сложность:**
- **По времени:** O(log n) — на каждом шаге отбрасывается половина оставшихся элементов.
- **По памяти:** O(1) — алгоритм работает in-place, использует фиксированное число переменных (left, right, mid), не выделяя дополнительную память.
- **Почему лучше рекурсии со срезами:** срез в Python `items[a:b]` создаёт физическую копию подсписка в оперативной памяти. При рекурсии со срезами суммарно выделяется O(n) новой памяти под копии плюс O(log n) на кадры стека вызовов. Итеративная версия не копирует список и не нагружает стек вызовов, расходуя строго O(1) памяти.
