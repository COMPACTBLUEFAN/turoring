### Период 2, неделя 3 · 27.07 – 02.08 · средний балл ~7.2
- **Go (`cli-log-analyzer`):** первый HTTP-сервер (`GET /api/stats`), второй эндпоинт `GET /api/logs?level=`, 5 тестов на `httptest`, исправлен баг с `os.Exit(0)`, `LoggingMiddleware` с тестом. Проект: 7+ коммитов, `cmd/` + `internal/`.
- **Python (`py-data-forge`):** pandas — `groupby` + `agg`, `apply` + `nlargest`, `pivot_table`, экспорт в JSON, тесты зелёные. Первый FastAPI-сервер (GET/POST, Pydantic, Swagger). Function calling — демо-скрипт. LangChain: LCEL, ConversationBufferMemory (заметил устаревание API).
- **Математика:** mean / median / variance / std вручную; ошибся с медианой чётного набора и сам нашёл ошибку; z-score объяснил отлично.
- **SQL:** SQLBolt 5–8 (JOIN, GROUP BY, HAVING); ошибка — не применил LEFT JOIN, чтобы найти «пустые» связи.
- **Прочее:** Git (stash, reflog, bisect, restore), CAP-теорема (хороший гибридный ответ: лайки = AP, покупки = CP), HTTP/2 и TLS-handshake, симметричное vs асимметричное шифрование (долг закрыт 31.07), бинарный поиск (решил рекурсивно с копированием срезов — O(n) памяти), Windows: `netstat -ano`, `Invoke-RestMethod`, Task Scheduler.
- **Код руками:** Go `ReverseString`, Python `flatten`, `Max`, `retry(n)` — к концу недели без ошибок.
- **Трудности:** декоратор с параметром (три уровня вложенности), мелкий синтаксис без IDE, путаница O(n) и O(log n).
- **Ошибки агентов:** вопросы по непройденным темам, подсказки с готовым ответом — пользователь справедливо ругался.
- **Оценки:** 8 · 7 · 8 · 6 · 7.
