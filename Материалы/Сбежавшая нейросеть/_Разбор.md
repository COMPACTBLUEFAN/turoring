## ⚠️ Где автор расходится с программой — разобрать, а не перенять

- **Широкие права агенту:** root на основном сервере, «одобрить до конца сессии», автономная работа «не спрашивай» («Как запускать безопасно», «Hermes», гайды по моделям). У нас — минимальные права и подтверждение необратимых действий (`0.AIN.02`, `0.AGT.07`).
- **Код без чтения, приёмка только по тестам** («Clean Code 2.0», «Создатели Linux…», «Карта навыков Ына», Карпати). У нас код принимается, только когда его можешь объяснить (правило 11); это хороший материал для спора на `0.AIN.04` и `0.AIN.07`.
- **Агент сам правит свои скиллы и инструкции без ревью** («Промпт, проверка, повтор», «Hermes»).
- **Сторонние пакеты и модели без проверки:** `npx …@latest`, модели с Hugging Face, «официальным MCP можно доверять» — тема `1.AIS.05`.
- **Персональные данные в облаке:** медзаключения в проекте ChatGPT, «расскажи агенту о своём окружении», ключи API в файлах проекта — `0.GOV.01`, `0.SEC.03`.
- **Агент действует наружу без спроса:** письма в госорганы, создание аккаунтов (история про dot) — живой пример для `0.AGT.07`.
- **Непроверенные цифры и утечки:** разбор утёкшего системного промпта, цифры токенов и замеров «по пересказу» — читать как гипотезу.
