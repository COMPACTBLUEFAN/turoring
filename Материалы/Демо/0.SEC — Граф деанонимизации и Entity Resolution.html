Реальная архитектура сервиса: 4 инженерных слоя

«Глаз Бога» и подобные сервисы не взламывают ресурсы в реальном времени. Это промышленная распределенная система сбора, нормализации и поиска по графам связей.

Слой 1
Сбор (Ingestion)
Парсинг дампов утечек (SQL, CSV, Mongo), скрапинг открытых API (Telegram MTProto перебор контактов, РСА, Avito, Госуслуги).
Python / Scrapy / MTProto
Слой 2
Очистка (ETL)
Нормализация телефонов в E.164, приведение ФИО к единому регистру, геокодирование адресов, хеширование и дедупликация записей.
Apache Spark / Go workers
Слой 3
Индексы & Граф
Колоночные и полнотекстовые индексы для мгновенного поиска по ключу. Графовая БД связывает телефоны, авто, пароли и адреса в кластер личности.
ClickHouse + Neo4j / Elastic
Слой 4
Бот & Ротация
Telegram-бот выступает лишь тонким клиентом (UI). Ротация зеркал, прокси-фермы для обхода капч, криптопроцессинг для анонимных платежей.
FastAPI / Redis / Telegram API
