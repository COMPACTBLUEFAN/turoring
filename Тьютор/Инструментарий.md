# 🧰 Инструментарий

> Справочник инструментов, которые пользователь попросил описать: агенты, CLI, библиотеки, сервисы, плагины, программы. **Заполняет Тьютор по запросу** («добавь в инструментарий X», «что за инструмент Y — запиши») — `Тьютор/ВОРКФЛОУ.md`, режим Г → «Инструментарий».
> **Как вести:** одна карточка — один инструмент, в своём разделе, разделы по алфавиту внутри. Факты — только проверенные по официальному сайту или документации (правило 6), с датой проверки. Если инструмент уже есть — обновить карточку, а не заводить вторую. Попробовал руками — дописать в «Мой опыт».
> **Не для этого файла:** кино, книги, игры и идеи проектов — `Тьютор/Банк идей.md`; новости и релизы — `РАДАР.md`.

**Формат карточки:**

```markdown
### Название
- **Что это:** 1–2 предложения простыми словами.
- **Зачем мне:** какую задачу решает в моей работе или учёбе.
- **Где в программе:** код занятия, интерес или практика (если есть).
- **Как начать:** установка или вход, первая команда — коротко.
- **Цена и лицензия:** бесплатно / платно / open source — какая лицензия.
- **Похожие:** 1–3 альтернативы и чем отличаются.
- **Риски:** что даёт доступ к данным, секретам, системе; на что смотреть.
- **Ссылки:** официальный сайт или документация.
- **Добавлено:** ДД.ММ · по запросу «…» · проверено: ДД.ММ
- **Мой опыт:** (дописывается, когда попробовал)
```

## 🤖 Агенты и AI-инструменты

### GitHub Spec Kit (`spec-kit`)
- **Что это:** Набор инструментов от исследовательской лаборатории GitHub Next для ведения разработки через спецификации (Spec-Driven Development) с AI-агентами (Claude Code, Copilot, Gemini CLI).
- **Зачем мне:** Управлять созданием фичей по шагам: Конституция (`constitution.md`) → Требования (`spec.md`) → Архитектурный план (`plan.md`) → Задачи (`tasks.md`) → Реализация. Защищает от «вайб-кодинга» и хаоса в кодовой базе агентов.
- **Где в программе:** `0.AIN.03` (Spec-Driven Development), практика недели (правила и полигон), `0.AIN.07` (контекст проекта).
- **Как начать:** Установка через uv: `uv tool install specify-cli --from git+https://github.com/github/spec-kit.git`. Инициализация в проекте: `specify init <project-name> --ai claude`.
- **Цена и лицензия:** Бесплатно, Open Source (лицензия MIT, GitHub).
- **Похожие:** AWS Kiro (агентная IDE со встроенным SDD), Tessl (Spec-as-Source платформа с реестром спек).
- **Риски:** Доступ агента к файлам репозитория при генерации; требует человеческого ревью каждого артефакта перед переходом к коду.
- **Ссылки:** [GitHub репозиторий: github/spec-kit](https://github.com/github/spec-kit)
- **Добавлено:** 26.10 · по запросу «Добавь этот spec-kit» · проверено: 26.10
- **Мой опыт:** Установлен через `uv tool install`. Используется для изучения структуры папки `.spec/` и слэш-команд управления спецификацией.
