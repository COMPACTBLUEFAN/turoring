# /learn — объяснить тему

Тема: $ARGUMENTS. Если пусто — возьми тему открытой сессии или спроси одной строкой.

Прочитай `Тьютор/ВОРКФЛОУ.md` и действуй по нему: старт (раздел 2) → **режим Б «Объяснить тему»** → запись в журнал Тьютора (раздел 5). Оценок и записей в трекер нет.
