# /interest — интересы

1. **Без аргумента или «список»** — покажи очередь: два интереса этой недели (пн, чт) и их статус, закрытые, следующие 4, часы против ~20%.
2. **Код или тема** — пользователь выбирает сам (правило 27, «Выбор пользователя»):
   - код из очереди — выбранное становится текущим, текущее меняется с ним местами в расписании;
   - тема вне очереди — нарежь 1–3 занятия по ступеням «Полки интересов» в `ROADMAP.md`, дай коды следующими номерами; первое встаёт на место текущего, текущее и всё после него сдвигаются на один слот;
   - текущий файл интереса без ответов — замени его; с ответами — оставь открытым (переезжает на новое место вместе с ответами), новый добавь следом. Открытых интересов — не больше двух;
   - обнови `НЕДЕЛЯ.md`, «Корректировки» трекера, порядок в `РАСПИСАНИЕ.md`; новое занятие (тема вне очереди) — ещё и в таблицу интересов фазы в `ROADMAP.md`. Запрос пользователя на смену интереса — это и есть его согласие на такую правку ROADMAP.
3. **«сам прошёл <что>»** — засчитай коротким разбором (правило 27, «Сделано самостоятельно»): выдай вместо занятия файл с 2–4 вопросами «что понял и как это связано с ядром», очередь сдвинь вперёд.
4. **«строго»** — интерес становится блокирующим (правило 27): пометь в трекере и `НЕДЕЛЯ.md`. **«как обычно»** — сними пометку.
5. Перечитай файлы перед правкой и проверь после записи (пользователь мог править его в Obsidian).
6. Ответ — 2–4 строки: какие теперь интересы недели и что поменялось в очереди.
