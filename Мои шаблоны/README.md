# 🧱 Мои шаблоны — вечные артефакты

> **Что это.** Личные шаблоны для **настоящих дел** — проектов, документов, процессов. Новое дело начинается не с нуля: берёшь подходящий шаблон и дописываешь только своё (места помечены `[дописать: …]`).
> **Любые сферы, не только IT:** код и агенты, бизнес и документы (`STR`, `BIZ`), право (`LAW`), звук (`SND`), работа и жизнь — всё, где одно и то же приходится делать повторно.
> **Не путать с `Шаблоны/`** — там шаблоны учебного процесса (неделя, сессия, спека и ADR для практики).
> **Откуда берутся.** Каждая фаза добавляет 1–3 шаблона: они собираются в занятиях фазы и сдаются на чекпоинте как обязательные артефакты (ROADMAP, «Вечные шаблоны»; `AGENTS.md`, сценарий F). Какие шаблоны даст следующая фаза — решается на чекпоинте текущей. Сверх этого — из интересов, проектов и по просьбе пользователя, в любой момент.
> **Кто правит.** Автор — пользователь (агенты помогают собрать). Агенты правки только предлагают; вносятся они с согласия пользователя, со строкой в «Истории».
> **Актуальность.** Шаблоны сверяются с передовыми подходами и с тем, что происходит в отрасли: на квартальном аудите (сценарий J2, «Технологический скан») и на каждом чекпоинте (сценарий F). Новость, которая задевает шаблон (новый стандарт, новая возможность агентов, изменение закона, громкий инцидент), — пометка «⚠ ждёт сверки» в реестре до ближайшего аудита.

## 🤖 Семейство `AGENTS.md` — файлы правил для агентов под разные проекты

Не один шаблон на всё, а **набор вариантов под разные проекты и сферы** — папка `AGENTS/`, один файл — один вариант. В шапке каждого варианта — **«Подходит из коробки для»**: каким проектам он годится без переделки (сфера, стек, роль агента, уровень риска), и **«Не подходит для»**.

**Новый проект — порядок:**
1. Найди в таблице ниже вариант, чьё «Подходит из коробки» совпадает с проектом.
2. Совпал — копируй в проект и дописывай только места `[дописать: …]`.
3. Не совпал — **пересмотр** ближайшего варианта: что в нём не годится для нового проекта (роль агента, команды, запреты, проверки, секреты, правила для данных), что добавить, что убрать. Итог пересмотра:
   - отличия частные, только для этого проекта, — правишь копию в проекте, вариант не трогаешь;
   - отличия повторятся в похожих проектах — **новый вариант** со своим «Подходит из коробки для», ссылка на родителя и строка в «Истории»;
   - отличие оказалось общим улучшением — правка самого варианта (с согласия), его «Подходит» расширяется.
4. Строка в таблице вариантов.

| Вариант | Подходит из коробки для | Родитель | Статус | Сверен |
|---|---|---|---|---|
| `AGENTS/<назначение>.md` — первый вариант | Определится в `0.AIN.08` (неделя 8) по полигону: личный Python-проект, агент пишет код, человек пишет спеки и ревьюит | — | 🔒 | — |
