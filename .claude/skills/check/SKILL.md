# /check — проверка сданного

1. Порядок старта — `AGENTS.md`, раздел 2.
2. Найди всё сданное и непроверенное: файлы сессий, интересов и ивента интересов с заполненным «Время» и пустой «Проверкой» (ивент интересов — короткий разбор без оценки, правило 29); неоценённые мини-тесты; блоки практики, «кода руками» и теста недели в `НЕДЕЛЯ.md`. Аргумент сужает до конкретного файла.
3. Проверяй по сценарию B: оценки — раздел 6, код — правило 11, закрытие занятия — правило 20, интересы — правило 27, строка «Подсказки Тьютора» в отчёте — правило 28. Обязательно (сценарий B, шаги 2–3): минус — только с цитатой требования из задания и цитатой ответа; проход адвоката по каждому минусу; метки ❌ / 💡 / ⚖, оценку двигают только ❌. Пользователь возражает — «Спор по проверке» сценария B: одно сообщение, цитаты или «снимаю».
4. Обнови трекер, `НЕДЕЛЯ.md`, при необходимости `ЗАМЕТКИ.md`. Перечитай файлы перед правкой и проверь после записи.
5. В ответе по каждому пункту: вердикт, оценка с обоснованием, что исправить, где ответить на мини-тест. Затем — **хвосты недели** (сценарий B, шаг 7): открытые интересы, практика, «код руками», мини-тесты, тест недели, долги — по каждому «когда лучше». В конце предложи /session (или /homework, чтобы пройти сессию с Тьютором).
