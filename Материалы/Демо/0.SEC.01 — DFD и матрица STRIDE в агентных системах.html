Правило соответствия DFD ↔ STRIDE

В классической модели Microsoft и OWASP элементы DFD подвержены только строго определённым угрозам:

Элемент DFD STRIDE
External Entity (Внешняя сущность) ✓—✓———
Process (Процесс / Код) ✓✓✓✓✓✓
Data Store (Хранилище / Файлы) —✓✓✓✓—
Data Flow (Поток данных / Сеть / IPC) —✓—✓✓—
💡 Главное правило границы:
Поток внутри одной зоны доверия часто защищён правами ОС. Но как только поток пересекает границу доверия (красный пунктир), угрозы T (подмена), I (утечка) и D (DoS) становятся критическими.
